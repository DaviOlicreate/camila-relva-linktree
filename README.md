# camila-relva-linktree

Link na bio. Página única e autocontida — não tem build.

    cd camila-relva-linktree
    vercel --prod

Fica em **camila-relva-linktree.vercel.app** (se o nome estiver livre).

## Instagram
Os embeds carregam sob demanda, quando a seção entra na tela.
Os posts ficam no atributo `data-posts` do `#ig-trilho` — formato `reel:CODIGO`
ou `p:CODIGO`, separados por vírgula. Trocar post é editar essa linha.

## Imagens
Ainda apontam para o site do cliente. Baixe para `img/` e troque por
caminho relativo antes de considerar definitivo.

## Pendências
Busque por `FALTA` no index.html.
